A control chat session

The operator drives the run conversationally from a laptop on the lab LAN. Reads are instant, mutations go through the versioned queue — and the hardware refusal is the design working, not failing: structured errors that the agent can explain instead of a stack trace.

A help session, inside the app

A dockable assistant pane in AutoLamella itself. Every claim is grounded — the answer cites the task history row, the log line, and the reference image it actually read, as chips the user can click. It can suggest the fix; doing it is gated behind arming the control scope.

An agent supervision session

The killer app. Each supervision checkpoint arrives as a prompt card with its context images; the agent inspects, answers through answer_prompt, and escalates when it isn't sure. The human sleeps until the one decision that actually needs them.
